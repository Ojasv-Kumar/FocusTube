Gemini AI

Keys are stored in this browser’s extension storage and sent directly to Google Gemini. Keep this extension folder private. Add as many keys as you have; FocusTube rotates between them if a key is rate-limited.

Fast and smart may be the same model. Fallback models are optional; if all keys and models fail, Learn restores native YouTube results and Interest/Curiosity show clearly labeled unranked results.

The first connection test asks the browser to allow FocusTube to contact Google’s Gemini API. Approve that permission for ranking to work.

Video search

Both retrieval sources now run directly from the extension. Auto uses the YouTube Data API when its key is saved, then falls back to YouTube search HTML. No localhost server is used.
