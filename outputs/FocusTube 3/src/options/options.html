Local AI · Ollama on your friend's Mac

Connect YourTube to a model running on a trusted local network.

Curiosity ranking and Learn query planning run on your friend's Mac. The bridge URL must use HTTPS, a private Wi-Fi IPv4 address, and port 11435. YourTube requests browser access only for the exact bridge host you enter. The bearer token is stored in this browser's extension storage and is sent only to that bridge.

One-time setup: on your friend's Mac install Ollama and run ollama pull qwen3:8b. In the included remote-ollama-bridge folder run ./generate-certs.sh FRIEND_MAC_PRIVATE_IP, copy only certs/ca.crt to your Mac and trust it in Keychain Access, then run ./start-bridge.sh YOUR_EXTENSION_ID. Copy the token from cat .bridge-token into this page. Full steps are in OLLAMA-REMOTE-SETUP.md.

Security: use this only on a trusted private Wi-Fi network. The bridge enforces HTTPS, a shared token, the exact extension ID, private-LAN clients, a small API allowlist, and keeps Ollama itself on localhost. Do not port-forward this bridge or use it on public Wi-Fi.
